# FlowMate — 具备反馈记忆的轻量个人事项 Agent

> 参加 **大工黑客松** | 赛道 1（奇绩创坛 · 为现实打个补丁） + 赛道 4（七牛云 · 轻量反馈记忆 Agent）

一款单文件 SPA，专注于"琐事快速收集 + 项目智能拆解重排"，并具备**反馈记忆闭环**——用户点 👍/👎 反馈后，系统自动抽取偏好沉淀到本地，下次处理时**显式应用**"已应用你的偏好"，让 AI 越用越懂你。

v1.3 版本已形成完整日常闭环：**今日计划时间线 + 一键智能排程 + 提前提醒 + 未来事项管理 + 每日回顾（过期未完成自动询问，可顺延）**。

## 🎯 双赛道亮点

### 赛道 1：奇绩创坛 · 为现实打个补丁

**真实问题**：大学生/职场新人每天面对大量待办、琐事、长周期项目——记在脑子里会漏，记在纸上不会自动拆解，滴答清单/Notion 不会记得你的偏好（「复习类任务别拆太碎」）。这是个没人解决的"小麻烦"。

**产品形态**：单文件 SPA，双击就能跑，5 秒分享链接跨设备传播。

### 赛道 4：七牛云 · 反馈记忆 Agent

**核心闭环（五步可演示）**：

```
输入文本/图片 → AI 解析（注入偏好上下文）
                ↓
用户反馈 👍/👎（带原因）
                ↓
关键词 + 规则引擎抽取偏好（拆解粒度 / 优先级风格 / 排期密度）
                ↓
localStorage 持久化（权重随反馈次数自然衰减）
                ↓
下次处理时显式应用（横幅高亮「已应用你的偏好」）
```

**记忆成本**：几乎为零（纯前端，关键词匹配，无 token 消耗）
**记忆效果**：可见（横幅高亮"已应用你的偏好"）
**准确性**：用户可随时启用/停用某条偏好

## 🛠 技术栈

- **前端**：HTML + 原生 JavaScript（无 React/Vue）
- **样式**：Tailwind CSS（CDN 运行时版）
- **图标**：FontAwesome 6
- **压缩**：LZString（URL 分享链接压缩）
- **存储**：localStorage
- **AI 接口**：DeepSeek Chat Completions（OpenAI 兼容）
  - 文本：`deepseek-chat`
  - 视觉：`deepseek-v4-flash-vision-exp`（多模态，2026-08-21 上线）
- **拖拽**：HTML5 原生 Drag & Drop API

## 🔑 如何接入 DeepSeek（可选，不填也能用模拟模式）

应用支持「**模拟模式**」和「**真实 API 模式**」双通道，**不填 Key 也能完整体验所有功能**。

如需真实 AI 能力：

1. 访问 [platform.deepseek.com](https://platform.deepseek.com/) 注册账号
2. 进入「API Keys」页面 → 创建新 Key（格式 `sk-...`）
3. 在应用内点击顶栏 **⚙ 设置** → 粘贴 API Key → 保存
4. 顶栏点击「模拟」按钮 → 切换为「真实」模式
5. （可选）调整文本/视觉模型名

**模型默认值**：
- 文本：`deepseek-chat`
- 视觉：`deepseek-v4-flash-vision-exp`（实验性多模态模型，单图 ≤384 tokens，成本极低）

## 🧠 记忆系统设计

### 偏好类型

| 偏好 Key | 名称 | 取值 | 抽取关键词示例 |
|---|---|---|---|
| `granularity` | 拆解粒度 | fine / medium / coarse | 「太碎」「再细点」「别这么细」 |
| `priorityStyle` | 优先级风格 | urgentFirst / importantFirst / easierFirst | 「先做截止」「重要的事先做」「先易后难」 |
| `density` | 排期密度 | tight / normal / loose | 「别排太满」「加紧」 |

### 权重机制

- 初始 weight = 0.5
- 每次被用户 👎 反馈触发 → weight += 0.15（封顶 1.0）
- 每次被 AI 应用 → appliedCount += 1
- weight ≥ 0.5 时**显式注入** AI prompt
- 偏好面板可手动「启用/停用/删除」

### 记忆日志

每次反馈/应用/导入/清空都生成一条日志，含时间、类型、详情。最多保留 200 条。

## 🛡 隐私说明

- ✅ **所有数据存储在浏览器 localStorage**，不上传任何服务器
- ✅ **API Key 仅存本机 localStorage**，不发送第三方
- ✅ 分享链接数据在**客户端** LZString 压缩/解压，服务端不参与
- ⚠️ 清除浏览器数据 = 清空所有任务和记忆（建议定期用「导出 JSON」备份）

```

```

```
==== STATE ====      应用运行时状态
==== RENDER ====     各区域 DOM 渲染
==== EVENTS ====     事件绑定
==== APP ====        初始化
```
