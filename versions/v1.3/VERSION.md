## 技术要点

- 单文件 `index.html`（约 2500 行），原生 JS 模块化（CONFIG/UTILS/STORE/RULES/AI/STATE/RENDER/EVENTS/APP/REMINDER）
- localStorage 持久化（key: `flowmate:v1`），零后端
- Tailwind CSS（CDN）+ FontAwesome 6 + LZString（URL 分享压缩）
- DeepSeek 双通道：模拟模式（无 Key 可完整体验）+ 真实 API（`deepseek-chat` / `deepseek-v4-flash-vision-exp`）

## 核心功能清单

1. 双模式：琐事快速收集 / 项目智能拆解重排（看板 TODO/进行中/完成）
2. 智能输入：文本 / 图片（视觉识别）/ 语音，自动解析时间、日期、优先级
3. 今日计划 + 一键智能排程：优先级优先 + 时长降序贪心插槽，冲突自动让位
4. 提前提醒：提前 N 分钟（默认 20）Notification + 横幅
5. 未来事项管理：未来日期任务自动归入折叠面板，不占用今日时间线
6. 每日回顾：过期未完成事项自动询问，完成/顺延/改天三种决策 + 批量按钮
7. 反馈记忆闭环：👍/👎 → 关键词抽取偏好 → localStorage 沉淀 → 显式应用
8. 记忆日志面板：偏好可查看/启停/删除，日志保留 200 条
9. 分享/备份：URL LZString 压缩分享 + JSON 导出/导入（按 id 去重合并）
10. 5 级错误兜底：网络失败/超时 → 重试 → 本地规则 → 切模拟，演示永不翻车
