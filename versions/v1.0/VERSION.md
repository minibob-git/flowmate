## v1.0 包含的功能
- 双模式：琐事快速收集 / 项目管理
- 智能输入（文本 + 图片视觉识别 + 语音输入）
- 项目智能拆解（模拟 / 真 DeepSeek API 双模式）
- 智能重排（基于优先级 / 截止日期 / 偏好记忆）
- 反馈记忆闭环（👍/👎 → 偏好抽取 → 存储 → 检索 → 显式应用 + 记忆日志面板）
- 任务编辑（标题 / 优先级 / 截止日期 / 预估时长）
- HTML5 拖拽排序（看板内）
- URL 分享（带数据）+ JSON 导出
- API 模式切换（模拟 / 真 DeepSeek）
